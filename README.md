# 🚀 Job Portal - MERN Stack

A full-featured **Job Portal Web Application** built using the **MERN Stack** that connects recruiters and job seekers through a modern, responsive, and secure platform. Recruiters can manage companies and job postings, while candidates can explore jobs, apply online, and manage their profiles.

---

## 🌐 Live Demo

**Frontend:** https://job-portal-project-coral.vercel.app

**Backend API:** https://job-portal-project-9xc9.onrender.com
